- HTTP 异常通过抛出带 `status` 和 `code` 字段的 `HttpError` 实例表达，由顶层 `(err, req, res, next)` 中间件统一映射为 `{ error, message }` JSON。
- 数据库访问通过 `initDb` / `getDb` 工厂创建连接，而非直接 `new Database()`，便于在入口复用连接并在测试中替换为 `:memory:`。
- Schema 变更采用「DDL 常量 + `ensureColumn` 列级增量」方式，避免全量重建表，旧库升级通过显式调用保证字段存在。
- 对外部不可信输入（如 LLM 输出）使用自定义解析器逐字符扫描而非直接 `JSON.parse`，失败回退到 null 交由上层原错误处理。
