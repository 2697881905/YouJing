模块由三个层次组成：
- 进程入口 `index.js`：通过 `dotenv.config()` 加载配置，创建 Express 应用并挂载全局中间件（注入 `req.db`、统一错误处理），按 `/v1/{device,entitlement,trip,pick,iap}` 挂载各业务路由，健康检查 `/health` 会真实执行 `SELECT 1` 以验证 SQLite 可用。
- 数据层 `db.js`：基于 `better-sqlite3` 提供 `initDb(path)` 和 `getDb()` 两个工厂；DDL 在模块顶层常量中集中声明，并通过 `ensureColumn` 做列级增量迁移；WAL + foreign_keys pragma 启用；支持 `:memory:` 测试模式与通过 `DB_PATH` 环境变量把数据库放到可写卷上。
- 共享工具 `lib/`：`http-error.js` 导出带 `status`/`code` 字段的 `HttpError` 类，被全局错误中间件消费；`json-extract.js` 提供 `parseFirstJsonObject`，用括号深度+字符串转义扫描第一个完整 JSON 对象，用于从 LLM 输出中安全提取结构化结果。
依赖方向单向：入口 → db/lib；lib 之间无相互依赖。
