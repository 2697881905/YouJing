以 `src/index.js` 为唯一进程入口：启动时初始化 SQLite（含迁移）、注册全局中间件链（auth → rateLimit → idempotency），再挂载各 `routes/*`；路由仅负责参数解析与响应编排，业务逻辑下沉至 `services/*`（华为 Token 验签、JWS/IAP 校验、LLM 代理、额度/配额查询、Pick 守卫等）。Prompt 契约通过 `prompt/contract.js` 导出 JSON Schema，由 `prompt/trip-validator.js` 在服务端校验 LLM 结构化输出，并与端侧 `prompt/generated/ai/PromptBuilder` 保持双向一致。共享基础设施集中在 `lib/`（HTTPError、JSON 提取）与 `db.js`，测试套件按模块一一对应覆盖中间件、路由与服务。
