- 测试文件通过设置 `process.env.JWT_SECRET`、`HUAWEI_CLIENT_ID`、`DEEPSEEK_API_KEY` 等环境变量注入运行时配置，而非硬编码到被测代码。
- 需要持久化的测试统一使用 `initDb(':memory:')` 创建内存数据库，并在 `after` 钩子中调用 `db.close()` 释放连接。
- 对外部 HTTP 依赖（JWKS 端点、上游 LLM）通过 `http.createServer` 在 127.0.0.1 随机端口上本地启动，并用 `after` 关闭。
- 涉及证书链的用例由 shell 脚本 `gen-test-certs.sh` 生成测试材料，JS 测试只消费产物而不直接生成证书。
