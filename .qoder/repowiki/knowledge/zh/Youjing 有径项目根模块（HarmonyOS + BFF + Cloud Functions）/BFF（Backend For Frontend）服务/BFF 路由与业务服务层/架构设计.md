- 目录按职责分为两层：`routes/` 暴露 Express `Router`（device、entitlement、iap、pick、trip），仅负责参数边界校验、调用下游 service、映射错误码；`services/` 为无状态纯函数或外部依赖封装（admin、huaweiIdToken、iapJws、iapNotify、llm、pickGuard、quota）。
- 依赖方向单向：route → service，service 不反向 import route；数据库访问集中在 route 层通过 `req.db`（better-sqlite3）执行 SQL，service 不持有连接。
- 安全能力下沉到 service：华为 Account Kit idToken 本地验签（RS256/PS256 + JWKS 缓存）、华为 IAP JWS 本地 ES256 验签（X.509 证书链 + RootCaG2Ecdsa.cer 信任锚），二者统一返回 `{ ok, reason }` fail-closed 语义。
- AI 精选流程由 `pickGuard.js` 提供请求体校验与候选集守卫，限制模型只能在候选池内排序、不得新增 id。
- LLM 代理（deepseek）通过 `buildLlmRequestBody` 构造 JSON Schema 请求体，并对外抛出自定义 `HttpError`（429/502/504）供上层统一处理。
- 配置集中走 `process.env`（HUAWEI_CLIENT_ID、JWT_SECRET、LLM_BASE_URL、DEEPSEEK_API_KEY、IAP_ROOT_CERT_PATH 等），未配置时走默认值或返回 NOT_CONFIGURED。
