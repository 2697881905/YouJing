- 外部签名验证（华为 idToken、IAP JWS）统一返回 `{ ok: boolean, reason?: string }` 的 fail-closed 结果对象，而非抛异常，由调用方区分部署态失败（如 NOT_CONFIGURED）与业务拒绝。
- HTTP 路由中的入参校验放在任何远程调用之前，对缺失/类型不符/超长字段直接返回 400 + 结构化 error/message 响应。
- 幂等写入统一采用 `INSERT OR IGNORE` 配合后续 SELECT 重取，避免 UNIQUE 约束触发 500（account、trip_pass、order、subscription 均如此）。
- 客户端自报的身份标识（unionId、purchaseToken、productId）一律不被采信，权威值取自已验签票据（idToken.sub、JWS payload）或 JWT bearer token。
- 可配置项通过 `process.env` 读取并提供 DEFAULT_* 常量兜底，并在运行时以 `xxxConfigured()` 形式暴露配置就绪探测。
