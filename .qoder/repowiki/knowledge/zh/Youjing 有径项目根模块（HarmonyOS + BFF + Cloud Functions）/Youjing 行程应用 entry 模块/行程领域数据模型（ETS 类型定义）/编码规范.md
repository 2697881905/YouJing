- 枚举值采用英文稳定码（如 'booked'/'leisure'/'economy'），中文展示文案由 UI 层映射，不在模型中混入显示文本。
- 对外数据契约以 TypeScript-style `interface` 描述，可选字段显式加 `?`，空语义通过可选属性而非 null 表示。
- 每个模型文件顶部保留 JSDoc 风格注释，标注对应开发文档章节编号（如 §3.1/§3.2/§4.1）并说明字段约定（日期/金额单位等）。
- 领域内共享的稳定码通过同模块的 enum 复用（如 `PlanParams.style` 复用 `TravelStyle`，`selectedArea` 复用 `AreaPriceTier` 码值），避免散落字符串字面量。
