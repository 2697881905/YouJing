本模块是纯类型声明层（无运行时逻辑），按业务域拆分为独立 `.ets` 文件：
- 核心聚合根：`Trip.ets`（`Trip`/`TripDay`/`Activity`/`Meal` 等，注释标明与 `ai/TripSchema.ets` JSON Schema 同源）。
- 规划输入：`PlanParams.ets`（`PlanParams`/`FlowQuestion`/`PaceRule`，作为 PromptBuilder 的输入聚合）。
- 内置资产：`Area.ets`（住宿区域库）、`Spot.ets`（景点库，含 `SpotBooking`/`DataProvenance`）。
- 交互态：`Account.ets`（UnionID 登录态 + 分区键）、`Pick.ets`（P1 AI 精选候选与排序结果，用于端↔BFF 传输）。
- 辅助实体：`Checkin.ets`、`Replan.ets`、`Weather.ets`。
依赖方向单向向外：本层不 import 任何 UI 或页面组件；仅被 `data/`、`ai/`、`bff/` 以及页面层消费，自身只引入同层的 `Expense.CategoryBudget`、`Spot.SpotTag`、`Area.Area` 等基础类型，避免循环引用。
