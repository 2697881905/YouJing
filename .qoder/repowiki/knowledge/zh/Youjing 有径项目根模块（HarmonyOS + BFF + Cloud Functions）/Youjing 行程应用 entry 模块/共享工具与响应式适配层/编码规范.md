- 纯逻辑工具函数与系统 IO 解耦：先抽取可测试的纯函数（如 navInset.isThreeButton、responsive.listLanesForBreakpoint），再由胶水层负责读取 settings/windowSizeChange 并发布结果。
- 断点与响应式计算集中由 breakpointCenter.ets 统一监听，utils/responsive.ets 只做断点到档位/列数的映射，消费方不得自行挂 windowSizeChange。
- 需要 UIContext 的工具通过 module 级 sharedUiContext 变量 + setSharedUiContext 注入，避免在纯 util 文件中持有 this.getUIContext()。
- 对外暴露的常量（导航模式、覆盖层 id、阈值数字等）以 const 形式集中定义在文件顶部，便于 hypium 直接 import 断言。
- 单位严格区分：几何变量用 _px/_vp 后缀，px 经 ui.px2vp 换算后再参与布局计算，防止 vp 与 px 混用。
