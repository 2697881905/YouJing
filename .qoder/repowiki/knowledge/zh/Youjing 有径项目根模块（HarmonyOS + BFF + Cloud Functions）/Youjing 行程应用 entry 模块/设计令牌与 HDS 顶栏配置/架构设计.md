模块按视觉维度拆分为独立 token 文件：`ColorTokens.ets` 通过 `Resource` 类型暴露所有颜色并桥接 `resources/base` + `resources/dark` 两套 color.json，由系统 `ColorMode` 自动切换；`TypeTokens.ets` 定义九档封闭字阶（family/size/weight/lineHeight/tracking），同时导出 `FontFamilyNames`、`TYPE_FONT_FAMILY` 等「有据」同名常量供搬运组件原样引用；`RadiusTokens.ets`、`IconTokens.ets`、`LayoutTokens.ets`（及同目录的 `SpaceTokens`、`MotionTokens`）分别提供圆角、图标尺寸与布局尺寸；`HdsChrome.ets` 作为 HDS `UIDesignKit` 的适配层，把上述 tokens 注入 `HdsNavigationTitleBarOptions`，统一处理标题自绘、磨砂渐变、返回键占位与主题 tick 刷新；`CountRoll.ets` 是仅消费 token 的轻量展示组件，不反向依赖业务。依赖方向单向：`HdsChrome` → Color/Type/Space/Motion tokens，`CountRoll` → Color/Type/Space/Motion tokens，token 文件之间互不耦合。
