- Token 以 `interface XxxTokensType` + 同名对象字面量导出，值来自 `$r('app.color.xxx')` 或纯数值，调用方只读不可写。
- 对「有据」仓库中的同名字段保留别名（如 `secondary`、`tertiary`、`floatingBar`、`fontFamily`、`fontFamilySerif`、`tabularFeature`），以便搬运组件零修改引用。
- 封闭集通过额外导出数组（`ALLOWED_FONT_SIZES`、`ALLOWED_RADII`）对外暴露，供 `tools/audit_type.py` 等审计脚本校验。
- 颜色全部走 `Resource` 类型，仅 `glassClear`、`glassWhite` 两个透明色例外使用硬编码 `#AARRGGBB`。
- 字号、圆角、图标尺寸采用「固定档位 + 语义命名」（display/title/headline/body/small/caption/overline/navLabel 等），禁止在消费处插值新值。
- `HdsChrome` 与 `CountRoll` 等 UI 组件一律通过 `import type` 引入 HDS 接口，避免低版本设备 import 即崩。
