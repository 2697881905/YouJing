模块由三个独立工具类组成，均通过 `@kit.ArkData` 的 `preferences` 做本地键值存储，彼此无相互依赖：
- `PlanDraft.ets`：单例 `PlanDraft` 承载屏2~5 逐步填写的规划草稿（basic/style/stayTier/transit/paces/selectedSpots/selectedArea），对外暴露 `get()/fresh()/hydrate()/flush()`；冷启时由 `EntryAbility.bootstrap` 调用 `hydrate` 恢复盘上快照，深链/小艺可先 `markExternalWrite()` 抢占水合；写盘采用 500ms 防抖 + JSON 快照 + `validSnapshot` 形态校验。
- `SkillPrefill.ets`：`SkillPrefill` 作为小艺 Skill 与应用之间的临时通道（Skill 无法直接拉起 UIAbility），按 destination/start/days/people/savedAt 五字段持久化，`take()` 取走即删，超过 2h 视为过期。
- `CalendarSync.ets`：`CalendarSync` 通过 `@kit.CalendarKit` 将 Trip 的预约节点和每日行程写入本机日历账户 `com.youjing.app`，以 tripId 为前缀在 `youjing_access` 分片中记录事件 id 实现幂等清理；同时持久化三条 AccessFlags（calendar/card/remind）开关。
依赖方向单向向下：仅消费 `../model/*`、`../utils/*`、`../common/logger/Logger`，不反向被业务页引用。
