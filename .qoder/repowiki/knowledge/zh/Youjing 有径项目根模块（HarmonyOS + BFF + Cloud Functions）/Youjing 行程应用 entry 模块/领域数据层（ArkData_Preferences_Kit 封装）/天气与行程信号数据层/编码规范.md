- 所有外部可复用的阈值（降水概率 60%、高温 33°C、低温 0°C、偏离 1km/10min、落后 30min、顺延 15–120min 等）定义为文件级 const 并以 `static readonly` 暴露给调用方，避免硬编码散落各处。
- 对外接口采用纯静态类（`WeatherStore`/`WeatherAdvisor`/`TripSignals`），无实例状态，便于在页面 reload 时直接调用而不必管理生命周期。
- I/O 失败一律吞异常并通过 `Logger.warn(TAG, ...)` 记录，返回 `null` 而非抛错，使上层 UI 能在缺数据时优雅降级（不出天气行、静默跳过信号）。
