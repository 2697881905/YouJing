- 写操作统一通过 DatabaseHelper.write(context, async fn) 获取 RdbStore 并在事务内执行，读操作在需要多步查询时改用 DatabaseHelper.getStore 直接拿 store。
- 对象数组字段以 JSON.stringify 序列化存入 TEXT 列，读取时用本地 parseXxx 辅助函数解析并捕获异常回退为空数组。
- 可选字符串字段在写入时对 undefined 转为 null，读取时对空串或 null 转回 undefined，保持领域模型与数据库 NULL 语义一致。
- 批量 upsert 使用 insertSync + relationalStore.ConflictResolution.ON_CONFLICT_REPLACE，避免先删后插。
- SQL 查询中显式排序（如 ORDER BY day_index、ORDER BY grp, id、ORDER BY popularity DESC），注释强调不依赖 SQLite 隐式行序以保证 UI 切片可复现。
