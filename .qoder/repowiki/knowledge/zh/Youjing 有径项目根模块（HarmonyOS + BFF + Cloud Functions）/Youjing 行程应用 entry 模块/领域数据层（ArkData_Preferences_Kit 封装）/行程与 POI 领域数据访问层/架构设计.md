本模块由三个独立的 DAO 类构成，均位于 entry/src/main/ets/data/ 下，统一依赖 DatabaseHelper 作为事务与连接入口：
- TripDao：聚合根整存整取（saveTrip 删除后重插 trip/trip_day/activity/meal 全量行），列表走聚合 SQL 直接产出 TripSummary，详情 loadTrip 分三次 SELECT trip → trip_day → activity/meal 再拼装为 Trip 树；activity 主键以 `${tripId}:${activityId}` 前缀化避免跨行程冲突；所有写操作通过 DatabaseHelper.write 包裹事务，读操作按 user_id = AccountStore.uid() 做登录态隔离。
- SpotDao / AreaDao：内置库只暴露 saveSpots/saveAreas（批量 insertSync + ON_CONFLICT_REPLACE）与 loadByCity（querySql 返回 Spot[] / Area[]），是阶段 5 数据灌入通道。
依赖方向单向向外：DAO → model.* 类型定义 + DatabaseHelper，不反向引用上层业务逻辑。
