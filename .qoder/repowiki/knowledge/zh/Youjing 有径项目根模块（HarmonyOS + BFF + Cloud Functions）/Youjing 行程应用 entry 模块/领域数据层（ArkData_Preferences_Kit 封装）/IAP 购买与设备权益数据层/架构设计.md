本模块由三个职责分明的静态类组成，依赖方向单向：`DeviceActivator` → `EntitlementStore` + `DeviceTokenStore`；`IapStore` → `EntitlementStore`。
- `DeviceActivator.ets`：设备激活入口，调用 BFF `/v1/device/activate` 获取 `deviceToken` + `entitlement`，并维护 `activating` 防重入；`refreshEntitlement()` 用现有票据刷新 `/v1/entitlement`，401 时清 token 回退到完整激活；`reactivate()` 在票据失效后走“先清再激活”流程。
- `EntitlementStore.ets`：权益持久化与门禁判定。通过 ArkTS `preferences` 以 TTL=5 分钟缓存服务端配额快照（`youjing_entitlement`），提供 `mergeQuotaSnapshot` 做字段级合并（服务端显式 null 才覆盖旧值，缺省沿用旧值）；`canExport` / `canGenerate` 是纯函数式判定入口，受 `ApiConfig.DEV_SKIP_BFF` 开关旁路。
- `IapStore.ets`：华为 IAP 购买与校验。遵循官方契约——端侧只负责把 JWS 原文交给 BFF `/v1/iap/verify`，不自行验签；通过 `queryPurchases(UNFINISHED)` 定位对应 JWS，解码 payload 匹配 `purchaseToken`，再由 `finishPurchase` 确认发货。定义 `PRODUCT_ID_PASS` / `PRODUCT_ID_SUB_MONTHLY` / `PRODUCT_ID_SUB_YEARLY` 产品常量，`purchasing` 静态锁防止并发购买。
- 对外暴露的领域模型集中在 `EntitlementStore`（`Entitlement`、`PassInfo`、`SubscriptionInfo`、`QuotaSnapshot`），被 `IapStore` 和 `DeviceActivator` 共同消费。
