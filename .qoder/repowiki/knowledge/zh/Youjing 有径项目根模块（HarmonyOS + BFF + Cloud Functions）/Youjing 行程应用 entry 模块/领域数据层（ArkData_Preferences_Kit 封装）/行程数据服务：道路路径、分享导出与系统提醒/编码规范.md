- 每个类以 `const TAG: string = 'Data.<ClassName>'` 作为 Logger 标签，所有日志走统一 Logger。
- 对底层 Kit 调用统一包裹 try/catch，将 `BusinessError` 转成可消费的错误语义（如 RoadRouteStore 返回 null 让调用方回退、TripReminder 用 ReminderFailure.classify 分类 CAPABILITY/LIMIT）。
- 状态持久化采用 ArkData `preferences`，key 以应用前缀命名空间（如 `youjing_reminder`、`reminder_ids_`）避免冲突。
- 对外 API 以静态方法暴露，内部状态（缓存、偏好）也使用 `private static` 字段，保持无实例、线程安全的服务形态。
