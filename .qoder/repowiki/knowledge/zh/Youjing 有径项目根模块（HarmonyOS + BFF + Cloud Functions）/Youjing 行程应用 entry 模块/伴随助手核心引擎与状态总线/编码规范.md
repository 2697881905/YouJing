- 引擎方法以 static 纯函数形式暴露，对 Trip/GeoPoint 做不可变变换（如 `moveToTomorrow` 返回新 Trip 而非原地修改）。
- 外部可观察状态统一经 `CompanionStore` 的 AppStorage JSON 串通道读写，避免直接持有复杂嵌套对象引用。
- UI 无关的决策逻辑（停留闸 DWELL_MIN=3min、地理到达判定、计划匹配）集中放在 Engine 私有静态方法中，保持可单测性。
- 跨页面执行通过 `executor` 回调 + `pending` 队列的双阶段模式完成：先 queueAction，再由 OnTrip 的 takePendingAction 取走执行。
