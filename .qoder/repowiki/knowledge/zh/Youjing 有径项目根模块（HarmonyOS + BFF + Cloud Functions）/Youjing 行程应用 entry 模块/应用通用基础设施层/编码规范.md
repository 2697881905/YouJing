- 所有跨层抛出的错误统一包装为 `AppError`，通过 `fromError(code, error)` 工厂保留原始 cause，禁止直接向上抛出原生 Error。
- 对外暴露的配置以 interface + 默认对象形式提供（如 `ApiConfigType` / `ApiConfig`），默认值走本地开发地址，生产端通过替换文件注入。
- 日志统一经 `Logger` 门面调用，tag 以模块名传入并自动拼接 `YouJing.` 前缀，debug 级别受 `BuildConfig.IS_DEBUG` 门控。
- 常量与配置采用 ES module 的命名导出对象模式，避免类实例化，便于 tree-shaking 与单点维护。
