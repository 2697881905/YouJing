该模块按职责划分为若干并列子目录，无内部依赖层级，被上层业务模块单向引用：
- `config/`：集中定义 `ApiConfigType` 接口及默认实现（BFF、LLM、Replan、Weather 等 URL/超时/开关），是网络层唯一配置入口；另有 `AccountConfig`、`DirectConfig`、`MockConfig`、`PickConfig` 分别承载账号、直连、Mock 与图片选择器配置。
- `constants/`：纯常量对象（预算、构建开关、城市列表、法律声明、问答流程），被 UI 与逻辑层消费。
- `error/`：以 `AppError` 作为统一异常类型，携带 `ErrorCode` 数值码与可选 `cause`，配合 `FailureCopy` 提供失败文案映射。
- `logger/Logger.ets`：基于 `@kit.PerformanceAnalysisKit.hilog` 的静态门面，强制 tag 前缀 `YouJing.`，仅在 `BuildConfig.IS_DEBUG` 时输出 debug 级别。
- `location/`：封装 Geofence + ArrivalWatcher + ArrivalNotice，面向到达提醒场景。
- `weather/`：`WeatherClient` 负责 HTTP 调用，`WeatherParser` 解析 Open-Meteo 响应。
- `liveview/`：当前为空目录，预留扩展点。

依赖方向：本模块仅依赖系统 Kit 与自身 `constants`，不反向依赖业务层，形成稳定的横切基座。
