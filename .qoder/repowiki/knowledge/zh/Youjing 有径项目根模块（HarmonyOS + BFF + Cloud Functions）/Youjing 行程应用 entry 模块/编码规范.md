- 跨层共享的数据结构集中在 model_types 目录，页面与数据层均通过 import 引用而非重复定义
- 多用户数据隔离统一通过 AccountStore.uid() 获取当前用户标识后再访问 DAO/Store
- UI 主题色、字号、圆角等视觉属性从 design_tokens 引入，禁止在页面或组件中硬编码颜色值
- 网络与第三方 Kit 调用封装在 common_infrastructure 或 ai_pipeline 内，页面层仅消费 Promise 接口
- 错误处理统一走 common/error 下的 ErrorCode/AppError 映射，不在页面层自行拼接错误文案
