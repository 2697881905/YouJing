- 卡片数据以字符串键值对（如 r1t/r1n/r1c、stopTotal 等）在 FormBindingData 中传递，UI 组件通过 `@LocalStorageProp` 一一对应绑定同名属性。
- 2×2 与 2×4 两种尺寸共用同一 UI 组件，通过传入的 `dimension` 字段进行条件分支（`visibleRows`、`routeStrip`、row 切片等），而非拆成两个组件。
- 卡片进程与主应用共享 `WIDGET_DIM_PREFS` 偏好名来持久化 formId→dimension 映射，读取失败时统一降级为 `DIM_KEY_2X2`。
- 所有外部 I/O（preferences、TripDao、CalendarSync）都包裹 try/catch 并以 `Logger.warn` 记录降级路径，保证卡片刷新失败不会崩溃。
- 色彩不直接写色值，而是通过 `dotColor` 等本地映射函数查 `app.color.*` 资源，避免在卡片 UIContext 下无法访问 ColorTokens。
