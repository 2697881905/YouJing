模块由三个文件组成清晰的三层分工：
- AppRouter.ets 是**纯路由表**，通过 `@Builder` 导出的 `routerMap(name, param)` 把字符串路由名分派到各业务页面（TripInput / Itinerary / Expense / Trips / OnTrip / Share / Map / Badges / Review / Pricing / Settings / ProfileEdit），并对未知路由兜底到 ComingSoonPage；参数在进入页面前经 `asFailInfo`、`asEditTarget`、`tripIdOf` 做窄化与兼容旧深链。
- Index.ets 是 **@Entry @Component** 根组件，承载 HdsTabs + BottomTabBar 骨架，维护当前 tab、dock 液态选中胶囊、拖拽形变等状态，并通过 `navDestination(routerMap)` 把二级页 push 到外层 HOST_NAV 栈，同时挂上 longTakeTransitionHook 作为一镜到底转场入口。
- OnTripPage.ets 是「行进中」主屏，聚合行程、打卡、天气、围栏定位、重排建议、徽章等子系统，以 DayStop/CheckedRow 数据模型驱动时间线 UI。
依赖方向单向：Index → AppRouter → 各业务 Page；AppRouter 不反向 import Index，避免循环引用。
