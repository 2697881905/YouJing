模块按「提示词 → 传输 → 解析」三层组织：
- 提示词层：`PromptBuilder.ets` 是 SOT，集中维护 Trip 生成与 Pick 精选两套 system/user prompt，并内嵌 `TripSchema.TRIP_JSON_SCHEMA`；`PickClient` 复用同一套 prompt 构造精选请求。
- 传输层：通过 `LlmTransport` 接口解耦三种后端——`MockLlmTransport`（离线闭环，确定性合成合法 Trip）、`HttpLlmTransport`（经 BFF `/v1/trip/generate`，由 `buildTripGeneratePayload` 在 `TripRequestPayload.ets` 定义端侧契约）、`DirectLlmTransport`（直连 OpenAI 兼容端点，走 `DirectChat.ets` 单一 HTTP 收口）。`PickClient.pickSpots` 再叠加 AGC 云函数优先 → BFF → DirectChat → 确定性规则的四级回退。
- 解析层：`TripParser.ets` 对 LLM 返回的文本执行 extractJson + 逐字段 schema 校验，使用 `TripSchema` 常量做枚举白名单，失败抛 `AppError(ErrorCode.SCHEMA_VALIDATION_FAILED)`；`ReplanParser` / `TripParser` 分别服务重排与生成两条链路。
依赖方向单向：业务页面 → Client → PromptBuilder/DirectChat/BFF → Parser → model 类型，不反向依赖 UI。
