该模块是 .codeartsdoer/ 下的纯配置型子项目，按职责划分为若干并列子目录：
- agents/：待填充的 agent 定义入口（当前为空）。
- skills/：以独立文件夹组织可被 Doer 加载的技能包，每个技能含 SKILL.md + _meta.json/_meta-zh.json 元数据；目前仅 build-failure-analyzer 与 evidence-based-code-review 两个技能，harmonyos-arkts-release-fixes 尚未完成。
- rule/metadata.properties：规则元数据集中声明。
- mcp/mcp_settings.json：外部 MCP 工具连接配置。
- experience-reuse/：经验复用仓库，experiences/ 下按领域（architecture/coding-pattern/debugging/testing/workflow 等）分目录归档历史决策文档，文件名采用 YYYY-MM-DD-主题 命名；reflect-reports/ 存放反思报告；.manager-history.jsonl 与 .session-traces.jsonl 记录管理器与会话追踪。
- mem-exp-config.json：记忆与经验复用全局配置。
- temp/ 与 .codebase/：运行时临时与代码库索引缓存目录。
依赖方向单向：上层 Doer 运行时读取这些静态配置，本模块不反向依赖业务代码。
