根目录作为多子系统的装配层，按运行环境划分四个子模块：`app_entry`（HarmonyOS 端 ArkTS 应用）、`bff`（Node.js Express 聚合服务）、`cloud_functions`（AGC Node 云函数）、`dev_tools`（ArkTS/Python/Node/Ts 审计脚本），并由 `agent_config` 提供 CodeArtsDoer 协作配置。
- 构建编排：通过 `hvigorfile.ts` + `hvigor/hvigor-config.json5` 驱动 ArkTS 构建；`oh-package.json5` / `package.json` 分别管理 HarmonyOS 依赖与 Node/BFF 依赖。
- 运行时边界：客户端通过 `entry/src/main/ets/common/network/request.ts` 等网络层调用 `bff` 暴露的 REST 接口，BFF 再桥接 AGC 云函数与 LLM/SQLite；云函数与 BFF 之间无直接共享代码，仅通过 HTTP API 契约耦合。
- 资源集中化：`AppScope/app.json5` 与 `AppScope/resources/base/element/string.json` 提供全局应用元数据与多语言文案，供 entry 模块引用。
