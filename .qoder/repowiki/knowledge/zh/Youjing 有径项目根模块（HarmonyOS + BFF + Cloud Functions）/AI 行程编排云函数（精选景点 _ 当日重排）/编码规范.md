- 入口统一以 `handler(event, context, deps)` 形式暴露，并通过 `_test` 命名空间导出内部校验器供单测直接调用。
- 请求解析采用 `headerOf` + `parseBody` 双阶段：先按大小写不敏感匹配 `x-youjing-token`，再安全解析 string/object 两种 body 形态并限制 UTF-8 字节上限。
- 错误响应统一走 `fail(statusCode, code, message)`，客户端侧通过 `statusCode` 区分 401(鉴权失败)、422(参数校验失败)、502(上游异常) 等语义。
- 对外部 LLM 调用通过 `deps.fetch` 注入，测试中以 `llmReturning` 工厂返回 mock fetch，避免真实网络依赖。
- JSON Schema 版本化：replanDay 显式声明 `SCHEMA_VERSION` 并在 `normalizeRequest` 中拒绝不匹配的版本，便于未来向后兼容演进。
- 常量集中定义在文件顶部（MAX_*、UPSTREAM_TIMEOUT_MS、ANCHOR_CATEGORIES 等），并通过 `Set` 做 ID 去重与成员校验，避免重复逻辑分散。
