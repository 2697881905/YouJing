工具按语言与职责平铺在 tools/ 下，无共享库，依赖方向单向指向仓库源码：
- Python 审计器（audit_*.py）：基于正则解析 `.ets` / `color.json` / DESIGN.md，校验色值、对比度、字体族、几何常量、按钮宽度、卡片内边距、滚动行为、Material 规范等设计契约。
- TypeScript 离线断言（companion_check.ts、map_city_check.ts、trip_intent_check.ts 等）：直接 import 项目 model/companion 源码，通过 bundled tsc --strict 编译后由 node 运行，不依赖 @kit 与设备。
- Node.js 探针（bff_commercial_probe.mjs、check_cloud_deploy.mjs、probe_yangling_gen.mjs）：以真实 HTTP 或文件扫描方式验证服务端/部署产物，被 shell 包装隔离。
- offline_hypium/：为 Hypium 套件提供 ArkTS 标准库的 Node 替身（kit_arkts.mjs + shim.mjs + stubs.mjs），仅白名单映射能一一对上的 API。
- Shell 编排层（build_install.sh、verify_*.sh、probe_*.sh）：封装 hvigorw 构建、hdc 安装、临时目录拷贝，保证“构建成功 → 产物新鲜 → 安装成功”的原子链。
所有工具均通过 git -C REPO 调用仓库命令，定位到根目录 ../ 使用。
