- 每个 Python 审计器以三行 docstring 说明"为什么要有这个脚本"及用法/退出码约定，便于开发者快速理解准入条件。
- TypeScript 离线断言使用 ok()/eq() 辅助函数累计 cases 并在失败时抛错，由外层 verify_*.sh 捕获非零退出码判定失败。
- Shell 包装脚本统一用 set -euo pipefail + mktemp + trap 'rm -f ...' EXIT 清理临时日志，并把 hvigorw/hdc 输出重定向到文件后再 grep 判定结果。
- Node.js 探针通过 gate(name, cond, detail) 收集必守行为并按 PASS/FAIL/DEFECT 打印，最后汇总缺陷列表作为退出码依据。
