# 任意城市接入方案（Stage 2）

2026-10-31 · 已实施并真机取证（提交见 `Docs/INIT_REPORT.md` §5ci 续 50）
前置：`Docs/MapKit地点检索探针-2026-10-31.md`（Stage 1 字段与错误码）

## 目标

把行前规划从「内置五城」扩到「任意城市」：未内置城市用 Map Kit 地点检索现取
景点与住宿区，**结果只放内存、不写 RDB**；内置五城继续走种子库，行为不变。

## 数据流

```
用户输入城市（一句话 / 城市面板“其他城市”）
  → PlanRepository.loadSpots(city)
       ├─ 种子库有数据 → 原样返回（五城/杨凌）
       ├─ 京都 mock → 原样返回
       └─ 种子为空且 isMapCity(city) → MapKitCityStore.load(context, city)
  → MapKitCityStore（30min 内存缓存）
       searchByText('景点', cityId, isCityLimit=true, 3×20)
       → 地址归属校验（locality / adminLevel2 / adminLevel3）
       → dedupeSites（名称包含/近距同前缀）
       → nearbySearch('酒店') 按区县查供给
       → MapCityMapper.buildSpots / buildAreas
  → 屏4 / 屏5 / 屏6 复用既有流程；生成后的 Trip 照常落 RDB
```

### 城市归属校验（必须）

真机实测：无效 cityId（如「不存在市」）**不会报错**，而是返回全国结果
（红旗渠、岳阳楼、赛里木湖都出现），`isCityLimit=true` 也拦不住。
因此每条 POI 必须满足 `locality / adminLevel2 / adminLevel3` 之一包含城市名
（去掉尾部「市」）；否则丢弃。实测西安首条：`locality=''、admin2='西安市'、admin3='雁塔区'`，
所以 **adminLevel2 才是市级字段**，不能只看 adminLevel3。

### 去重

按检索顺序保留第一条：

- 归一化名称完全相同**且相距 ≤3km**（同名但更远视为不同地点，如两座「万达广场」）；
- 一个名称包含另一个且相距 ≤3km（西安城墙 / 城墙·碑林）；
- 同区县、相距 ≤500m、共同前缀 ≥3 字（秦始皇帝陵博物院 / 秦始皇兵马俑博物馆）。

### 字段口径

| 字段 | 口径 |
|---|---|
| id | `mk:<city>:<siteId>` / `mk-area:<city>:<区县>` |
| 热度 | **检索秩**（第 1 名 100 → 第 n 名递减到 5），不伪造评分 |
| 标签 | 只映射高置信 POI 类型：博物馆/景点/寺庙/地标→经典，动物园/水族馆/公园→亲子；映射不到进屏4「其他」分组 |
| 停留时长 | 按类型给保守默认，界面标「估算」 |
| 开放时间 | `poi.openingHours.texts` 经 `commonHours` 归并：只有「各天一致且单时段」才展示（如 8:30–17:00 / 全天开放）；闭馆、午休、多时段、各天不一致或没有数据一律留空，界面统一「以官方为准」 |
| 预约 | 一律 `requiresBooking=false`；**给 LLM 的提示词不再写「无需预约」**，改「预约信息未获取，以官方为准」，并禁止编造预约方式/提前天数 |
| 简介 | `abstractText/description` 截 80 字；没有则「区县 · 类型」 |
| 住宿区 | 按 `adminLevel3` 聚合质心；对 10 个区县查酒店供给，按供给降序、再按景点数取前 8；档位固定舒适并标「未校准」，通勤/餐饮留空 |

  检查网络后重试」，不写草稿。
- **屏4**：顶部「景点来自地图服务 / 停留时长为估算，预约与开放时间以官方为准」；
  MapKit 城市空态显示「地图服务没有返回 X 的景点」+ 重试/换城市；新增「其他」分组承接
  未映射类型。
- **屏5**：顶部「住宿区来自地图服务 / 按景点所在区县聚合；住宿档、通勤与餐饮未校准」；
  区县卡不再显示 0 分钟等假字段，改为未校准说明。
- **屏5b**：组头「地图服务区县」，三行元信息改为「舒适档（未校准） · 地图服务区县 /
  按景点所在区县聚合 / 通勤与住宿供给未校准」。
- **屏6**：地图城市缺景点/住宿区抛 `1004 MAP_CITY_DATA_FAILED`，屏7 标题「地图数据没取到」，
  副标题「地图服务没有返回这座城市的景点或住宿区，检查网络后再试」。

## 验收与边界

已验：西安一句话全链生成（54 条去重、6 区县、12 预选、碑林区）；
成都手工“其他城市”→屏4/屏5/屏5b；无效城市失败出口；内置北京种子路径不回归；
DB `spot` 仍 138 条（无 MapKit 落库）、孤儿 0。

未验/未做：评分与预约真实值（字段不存在）；开放时间只展示各天一致的时段，闭馆/午休/不一致
不展示；区县通勤/档位校准；酒店供给只做粗略排序，远郊县仍可能出现在屏5b（屏5 距离排序把
默认候选压到近处）；MapKit 配额与缓存许可；md/浅色档；成都只走到屏5，没有生成行程；
只有西安一次真实 LLM 生成。
