## 1. 本轮新增的硬事实（推翻 v1 三处前提）

| v1 我说 | 实测 | 后果 |
| --- | --- | --- |
| 「ArkTS 能否吃自定义贝塞尔未证实」 | **可用**：`MotionCurves.standard: ICurve = curves.cubicBezierCurve(0.2, 0.8, 0.2, 1)`，`import { curves } from '@kit.ArkUI'`，`.animation({duration, curve: MotionCurves.standard})` 在 `Pressable.ets:31` 真用着；另有 5 条 `curves.springMotion(response, dampingFraction)` | 契约 `curve-*` 全 6 条可直接实现，§1 的可行性实验取消 |
| 「有据 `blurRadius 50` 是偏离契约」 | 50 是**滚动门控**不是深浅门控：6 处 `blurRadius: this.xxxBarScrolled ? 50 : 0`，全在 `HdsNavigationTitleBarOptions.originalStyle.backgroundStyle` 内，配 `backgroundColor: Color.Transparent` + `maskExtraHeight: 0`，`scrollEffectType: IMMERSIVE_GRADIENT_BLUR`；`Index.ets:1800-1802` 记根因：**开关必须由绝对滚动偏移驱动**，用每帧增量正负驱动会被松手回弹的负增量打灭 | 有径**不是没有门控**——`design/HdsChrome.ets:36` 早就写着 `blurRadius: spec.scrolled === true ? BAR_BLUR_RADIUS : 0`，但 `ChromeSpec.scrolled` **全仓 21 个调用点一个都没传**（`grep -rn "scrolled" pages components` 除 HdsChrome 自身 0 命中，`onDidScroll`/`currentOffset`/`bindToScrollable` 各 0 处）⇒ **顶栏模糊今天恒为 0，从来没出过图**。这条同时解释了「24 出不出磨砂」为什么一直欠着：根本没有可量的东西。对齐 = 值 24→50 **且**把 21 个调用点接上真实滚动状态 |
| 「深色归零阴影是家族规则」 | 有据深色**不归零**：5 个 `ShadowTokens` 全是写死的黑 alpha（`#08/#12/#18/#26`），注释「黑 alpha 压深底本就几乎不可见，天然主题中性」；只有大面积落影升级为成对资源 `bar_shadow`（浅 `#2E1A1A1E` / 深 `#8C000000`，深色反而加到 55%）；另有 2 处按**材质**（非深浅）门控 `isSystemMaterialActive() ? none : cardContact` | 契约 §Elevation 那句「In dark mode drop the shadow」要改写，`audit_elevation.py` 的「深色必须归零」判据要**反转**，有径 8 处 `isDarkMode` 分支全删 |

另三条底座事实：

- **双层影可做**：ArkUI 单节点一层 `ShadowOptions`，有据用**两个嵌套 Column** 各挂一层（外层 `cardAmbient r10 off3`、内层 `cardContact r1 off0` + `border 1px separator` 描边），两层都铺不透明 `elevated`，所以内层被外层底遮住不露馅（`BaseCard.ets:32-47`）。
- **一镜到底的导航前置，有径壳合格、接地点全缺**：有径是 `HdsTabs` 4 TabContent + 每 tab 一个 `HdsNavigation(APP_NAV).mode(NavigationMode.Stack)`（`Index.ets:189/203/207`，四栈在 `common/constants/AppNav`，`stackOfTab` 于 `Index.ets:252`）；`onReady` 挂 8 处但**只取 `ctx.pathStack`**，`navDestinationId` 全仓 0 处、`customNavContentTransition`/`NavigationTransitionProxy` 0 处、`.transition(` 0 处。
- **改契约的红绿不对称**（这条决定 §5 的提交顺序）：`audit_geometry.py`/`audit_colors.py` **只遍历契约侧**，「仓库有、契约无」不报 → **加契约行才可能变红，删契约行只会变绿**；`audit_material.py` 读到 `glass-blur` 不等**只打 note 永不 fail**；`audit_fontfamily.py` 定义了 DESIGN 常量却**从未 open**（改 typography 段它 0 红，静默失真）；`audit_elevation.py` 解析的是**正文散文**（DESIGN.md:1048-1050 三条 bullet），散文一改整把尺失明退 1；`~/Pictures/有径/有径-设计底稿-v1` **不在 git 下**，同级有 `有径-设计底稿-v1.zip`。

## 附录 B：v1 数字的复算方式

`/tmp` 在本机重启即清空，所以历史计数不靠临时脚本存活。下面这段可整段粘进 `python3` 现场重算（2026-11-02 实测输出：46 个自写卡片节点、三元组达标 8 处、padding 为 `SpaceTokens.md` 18 处）；P2 之后这两个数由入库的 `tools/audit_family_card.py` 持续打印。

```python
import re, glob, collections
files = (glob.glob('entry/src/main/ets/pages/*.ets')
         + glob.glob('entry/src/main/ets/components/*.ets'))
pad = collections.Counter(); bg = collections.Counter(); n = tri = 0
for f in files:
    L = open(f, encoding='utf-8').read().split('\n')
    for i, l in enumerate(L):
        if '.borderRadius(RadiusTokens.card)' not in l:
            continue
        ind = len(l) - len(l.lstrip()); ch = []; j = i - 1
        while j >= 0 and L[j].strip():
            si = len(L[j]) - len(L[j].lstrip()); st = L[j].lstrip()
            if si > ind or (si == ind and st.startswith('.')):
                if si == ind: ch.append(st)
                j -= 1
            else: break
        ch = ch[::-1]; k = i + 1
        while k < len(L) and L[k].strip():
            si = len(L[k]) - len(L[k].lstrip()); st = L[k].lstrip()
            if si == ind and st.startswith('.'): ch.append(st); k += 1
            else: break
        c = ' '.join(ch); n += 1
        m = re.search(r'\.padding\(\{?\s*([^),}]*)', c); b = re.search(r'\.backgroundColor\(([^)]{1,30})', c)
        pad[m.group(1).strip()[:24] if m else '无'] += 1
        bg[b.group(1).strip()[:28] if b else '无'] += 1
        if m and m.group(1).strip() == 'SpaceTokens.lg' and 'surfaceElevated' in c: tri += 1
print(n, tri); print(pad.most_common()); print(bg.most_common())
```
