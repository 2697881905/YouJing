## 二、本轮修复清单（按风险排序，均已设备/构建验证）

### A. 数据层硬伤

1. **RDB 迁移链断裂**（`DatabaseHelper`）：`onUpgrade` 用 `oldVersion === N` 精确匹配，v1 老库升到 v4 时只执行一级 → `expense/checkin` 不建表、`expense.activity_id` 不加列（后续写库必报 no such column）。改为 `oldVersion < N` 累积式，新增 v5（`spot.confidence`）。实测 `迁移完成 4 → 5`。
2. **种子解析零校验**（`DataSeeder`）：`(bk['m'] as string).length` 等 20 处裸断言，缺一个键就在首启 bootstrap 抛 TypeError。补 `strOf/numOf/strsOf/objOf/pickEnum` 原语 + 枚举白名单 + 坏行跳过（返回 `Spot | null`）。
3. **白名单回退漏洞**（本轮测试抓出）：键存在但值非法时 `whitelist(...)[0]` 得到 `undefined` 写进库。改 `pickEnum(value, allowed, fallback)`；`toArea_whitelist_fallback` 用例先红后绿。
4. **分区键漏过滤**：`CheckinDao` 取消打卡、`ExpenseDao` 删除、`PlanRepository.hasTrips` 不带 `user_id` → 切换账号后可删到另一账号的数据。三处补齐（`hasTrips` 无调用方，直接删除）。
5. **`todayPlan` 全表遍历**：卡片刷新对每条行程整份 `loadTrip`（4 条 SQL）。改为按 `start_date <= today <= end_date` 预筛（日志由「行程数」改为「候选数」）。
6. **种子字段冒充**：`brief` 用「名称（区）」、`description` 用区域名顶替 → 一律留空（UI 也未消费），缺口登记在 §四-4。
7. **`isValidIsoDate` 只验格式**：`2026-02-30` 能穿透到草稿与深链参数，被 JS Date 规范化成 3 月 → 加真实日历回检（与 Skill 入口同口径），测试断言方向同步纠正。

### B. 功能缺陷（用户可见）

8. **屏7 重试把页面堆叠**：`popToName('Generating')` 落空（该页已被 replacePath 移出栈）后再 push，生成成功后 Itinerary 底下仍压着失败页。改 `replacePath`；「换一天 / 去掉这个景点」由裸 `pop()`（只会落到屏5）改为 `popToName(TripInput/SpotPick)` + push 兜底。
9. **屏4 容量条渲染「3.0 天」**、**屏2 默认日期写死在过去**（`2026-07-01`，且草稿默认值同样写死）：改按今天起算，草稿里的过期日期一律丢弃。实测屏2 `10月25日 – 10月27日`。
10. **屏2 预填城市被静默丢弃**：外部拉起「杭州」时界面显示北京、生成按北京走。改为如实回显；不支持的城市场景由屏4 空态说明（新增空态页）。
11. **屏6 取消后仍被拽走**：取消/返回后 in-flight 生成完成照样 `replacePath`。加 `cancelled` 标志（含 `aboutToDisappear`），关键 await 后短路。
12. **深链直达屏7/屏9 抛 TypeError**：`typeof null === 'object'` 仍会断言 null。`Index` 路由参数窄化改为普通函数 `asFailInfo/asEditTarget`（@Builder 内不允许局部 const）。
13. **屏1 登录/归户失败卡死**：`enterApp` 裸 await，一处 rejection 就停在首启页。包 try/catch，失败按游客分区继续。
14. **卡片空态可点**：无 tripId 时点卡落到空行程页。空态不响应点击。
15. **下一段通勤图标写死汽车**：地铁/公交段显示错图。抽 `utils/TransitSymbol`，屏8 与屏15 共用。
16. **`Progress` 缺轨道色**：屏4/屏6 补 `surface-sunken` 轨道。
