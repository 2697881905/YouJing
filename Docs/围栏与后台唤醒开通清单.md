## 四、边界与未验项

- 室内定位 acc≈237m 且坐标量化不抖动，**边界抖动法在室内无效**；ENTER 时延的真实体感
  需室外步行一次（判据 C）。
- 本 SDK（compatibleSdk 26.0.0）**已含** trigger 式实况窗符号
  （`startLiveViewByTrigger` / `isGeofenceTriggerEnabled`）：真机调用已过参数校验，
  最终返回 `1003500005 The right of liveView is not enabled`——缺的是 AGC 实况窗权益
  与重签含 `com.huawei.service.liveView.entry` 的 Profile，不是 SDK 能力。
  旧记录「本 SDK 无 trigger 式符号」作废。
- 探针包为 throwaway：默认界面不变、参数触发、测完已装回正式包；分支保留仅供复测。

## 五、代理提醒（P4）是第二道 AGC 闸门（2026-11-09 补）

P4 原判断是「端侧、不需 AGC」，真机实测推翻了这个前提：

| 事实 | 证据 |
|---|---|
| `publishReminder` 被管控 | 返回 `ungranted capability: com.huawei.service.notification.agentreminder` |
| 权限本身不是问题 | `ohos.permission.PUBLISH_AGENT_REMINDER` 已声明，SDK 定义为 `normal` + `system_grant` |
| 管控范围 | 官方文档：手机/平板/PC 有管控，智慧屏/穿戴无管控 |
| 官方替代 | Calendar Kit 写入带 `reminderTime` 的日程 |

**开通路径**（官方文档「代理提醒开放能力申请」）：

1. AGC → 项目设置 → 开放能力管理 → 「代理提醒」→ 申请；
2. 应用分类需属于旅游类等支持类型，场景填「行程提醒」；
3. 8 个工作日反馈；通过后勾选能力开关并保存；
4. **必须重新生成 Profile 并手动签名**，否则调试/发布包仍拿不到权益。

代码侧 `TripReminder` 已就绪（出发前 TIMER / 预约提前 CALENDAR / 晨间 CALENDAR）；
审批和重签完成后直接真机复验锁屏，不需要改代码。未通过前若必须锁屏提醒，
只能退回 Calendar Kit，但当前日历写入受 `canExport` 付费墙约束，是否接受这个降级需产品确认。
