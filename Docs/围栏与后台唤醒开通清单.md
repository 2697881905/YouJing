## 三、开通后复测清单（复用探针分支）

1. `git checkout spike/geofence-probe` → 构建 → `aa start … --ps geoprobe 1`（授权已持久化）；
2. 判据 A（前台）：围栏内 ≥15s 应出现 `fence[r100-inside] 事件 … DWELL`；
3. 判据 B（后台）：注册后按 Home 退后台 90s 再回前台，hilog 应含后台时段的事件时间戳
   （此判据同时验证闸门 2）；
4. 判据 C（半径）：r=100 注册与触发均正常后，再验 r=300 室外步行进入的 ENTER 时延；
5. 复测通过 → 切片 2 升 T2：`GeofenceManager`（独立 Manager，不放页面）+ 勋章落库；
   复测不通过 → 保持 T1 并在本文登记失败形态。

## 四、边界与未验项

- 室内定位 acc≈237m 且坐标量化不抖动，**边界抖动法在室内无效**；ENTER 时延的真实体感
  需室外步行一次（判据 C）。
- 本 SDK（compatibleSdk 26.0.0）无 trigger 式实况窗符号；锁屏承载以「通知 + 已审核通过的
  实况窗会话」为准，trigger 方案不纳入本期。
- 探针包为 throwaway：默认界面不变、参数触发、测完已装回正式包；分支保留仅供复测。
