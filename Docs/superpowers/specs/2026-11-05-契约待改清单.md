| 项 | 内容 |
| --- | --- |
| 契约原文 | `layout.floating-dock-bottom-margin: 28px`，注释「28px above the system nav inset」（DESIGN.md:235 / :1013） |

## C3 · 状态栏带子归谁 —— 真机证伪，契约保持原样

| 项 | 内容 |
| --- | --- |

| 迁移尝试 | 按 spec 的「无带子概念」：`ChromeSpec` 加 `barBackground`，撤掉 `pages/Index` 根 Column 那道按页签涂色 |
