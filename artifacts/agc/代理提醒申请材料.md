# 有径（com.youjing.app）· 代理提醒开放能力申请材料

## 一、应用信息
- 应用名称：有径
- 包名：com.youjing.app
- 应用分类：旅游类（旅行行程规划与行中陪伴）
- 申请能力：代理提醒（reminderAgentManager）
- 提醒场景类别：生活类提醒 —— 行程提醒（非广告 / 营销 / 优惠券 / 直播预约）

## 二、权限声明（module.json5 已声明，见附件原件）
```json5
{
  "name": "ohos.permission.PUBLISH_AGENT_REMINDER",
  "usedScene": {
    "abilities": ["EntryAbility"],
    "when": "inuse"
  }
}
```
该权限为 normal + system_grant，仅用于发布行程类定时提醒。

## 三、三类提醒场景（标题 / 文本 / 时间 / 频率）

### 1. 出发前提醒（TIMER）
- 时间：出发前一天 20:00
- 标题示例：明天出发去北京
- 文本示例：明天出发去北京，共 3 天。首日 09:00 故宫博物院 出发。
- 频率：每趟行程 1 次

### 2. 预约提前提醒（CALENDAR）
- 时间：游玩日 09:00 往前推 advanceDays 天（无提前量按 1 天兜底）
- 标题示例：预约提醒 · 故宫博物院
- 文本示例：需提前 7 天预约（以官方为准）
- 频率：每个需预约且尚未预约的节点 1 次；已约 / 无需预约不再催

### 3. 每日晨间行程播报（CALENDAR）
- 时间：行程期间每天 07:30
- 标题示例：Day 1 · 皇城根漫步
- 文本示例：今天 3 站：09:00 故宫博物院 → 15:00 景山公园
- 频率：行程期间每日 1 次

## 四、使用代理提醒的必要性
行程提醒时效性强（出发前 / 预约截止 / 每日晨间），用户不会持续打开应用；
应用退后台或进程被系统回收后，仍须由系统代理按时触达，普通应用内通知无法保证。
故申请代理提醒能力，仅用于上述旅行行程提醒，不做任何营销推送。
